## summary
The document constructs metastability-containing sorting circuits for Gray-code inputs by expressing comparison as an associative four-valued state transition and computing every prefix state in parallel. It extends the Ladner-Fischer parallel-prefix framework with arbitrary fan-out f ≥ 3 while retaining optimal depth and linear size. Post-layout results compare complete 4-sort/7-sort/10-sort networks against non-containing binary comparators.

### metastability_containing_gray_sort  (domain: other, closest: parallel_prefix, why_not: parallel_prefix supplies the comparison core but does not describe Gray-code sorting, metastability closure, or sorting-network composition)
mechanism: A 2-sort(B) circuit accepts two valid binary-reflected Gray strings, each containing at most one metastable bit. A four-state comparison machine is decomposed into the associative M prefix operator and an outM operator that produces the metastable closures of maximum and minimum. PPCM computes all prefix states in O(log B) depth/O(B) size. Substituting the resulting 2-sort elements into a sorting network yields metastability-containing n-input sorting. # p.1–8, p.16
