## summary
P-SFA approximates sigmoid with three fixed regions and assigns more piecewise-linear segments to regions containing more neuron values in each network layer. Each segment uses a 2^-n slope, so the FPGA datapath replaces multiplication with shifting and addition. The Xilinx Artix-7 implementation reports 6 mW power, 9.856 ns delay, and MNIST recognition accuracies of 97.46% for DNN and 99.02% for CNN. (pp.2-9)

## families
### sigmoid_tanh_pwl  (role: proposes)
mechanism: P-SFA exploits sigmoid symmetry, divides the positive semi-axis into approximate-linear [0,2.2), saturation [2.2,5), and constant [5,+∞) regions, and fixes the outer output to 0 or 1. Region I/II segment counts depend on each layer’s neuron-value probability distribution, while segment widths vary with the sigmoid second derivative. Three selectable functions F0/F1/F2 cover Region-I probabilities of 0%-30%, 30%-70%, and 70%-100%. Each segment computes x/2^n+b_i through a decoder, shifter/MUX, and adder. (pp.2-5)

### nonuniform  (role: instantiates)
mechanism: The segmenter first uses fixed sigmoid regions defined from derivative behavior and an error threshold. Region I/II receive probability-dependent segment counts, and interval widths vary according to the magnitude of the sigmoid second derivative. A hardware input decoder selects the corresponding b_i and n for each interval. (pp.2-5)

## space_gaps
* `sigmoid_tanh_pwl` lacks choices for probability-conditioned per-layer function selection and power-of-two slope quantization. (pp.3-5)
* `nonuniform.boundary_search` covers curvature-driven interval sizing but not probability-driven allocation of segment counts among fixed regions. (pp.3-4)
* `nonuniform.addressing` lacks a generic interval decoder value; the paper names an input function decoder but does not establish a comparator-tree implementation. (p.5)

## open_questions
* The paper does not state whether the decoder/MUX/adder stages are pipeline stages or only combinational processing stages.
* Table 2 prints Gomar’s maximum absolute error as `01667`; the missing decimal point must not be guessed.
* The paper does not specify the synthesis tool/settings, clock constraint, power-estimation method, or FPGA speed grade used for Table 10.
