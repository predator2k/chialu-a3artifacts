## summary
The paper specifies table-driven IEEE 754 implementations of log and log1p using working-precision arithmetic. The implementations combine argument reduction, tabulated split constants, and low-degree polynomial evaluation, with proved round-to-nearest error below 0.57 ulp. Tests cover single/double precision implementations on Sun 3 and VAX 8700 systems.

## families
### lut_plus_poly  (role: proposes)
mechanism: LOG reduces X to 2^m(F+f), where F=1+j2^-7 and |f|≤2^-8. Procedure 1 reconstructs mlog2+log(F)+log(1+f/F) from lead/trail table entries and a local polynomial. The local argument is either u=f/F, optionally using a stored reciprocal, or u=2f/(2F+f); Horner evaluation produces the correction before ordered reconstruction. # pp.380-385

### single_poly  (role: instantiates)

### region_dependent  (role: instantiates)
