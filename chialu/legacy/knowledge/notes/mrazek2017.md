## summary
EvoApprox8b provides 430 non-dominated approximate 8-bit adders and 471 non-dominated approximate 8-bit multipliers generated by multi-objective Cartesian genetic programming. The library supplies Verilog/Matlab/C models and characterizes each circuit by area/delay/power and seven error metrics.

## families
### approximate_logic_synthesis  (role: instantiates)
mechanism: Candidate combinational circuits are directed acyclic graphs encoded as Cartesian grids of programmable standard-cell nodes. Point mutation and NSGA-II search minimize MRE/power/delay, while multiple island populations exchange selected individuals. Thirteen conventional adder architectures and six conventional multiplier architectures seed the search, which returns non-dominated Pareto fronts rather than one circuit. # pp.259-260

### error_analysis_quality  (role: instantiates)
mechanism: Every library circuit is evaluated with HD, EP, MAE, MSE, MRE, WCE and WCRE. The error calculations enumerate all 2^ni input vectors, avoiding dependence on a sampled test-vector set. Circuit records also include area/delay/power and node count so Pareto points can be selected under common conditions. # pp.260-261

slots: none
parameters: all 2^ni input vectors; ni is the number of primary inputs and operand width is ni/2 bits   # pp.260-261

errors_and_checks: HD counts erroneous output bits; EP is the fraction of inputs producing an erroneous output; MAE/MSE/MRE are mean errors; WCE/WCRE are worst-case errors. All seven values are calculated for every library circuit. # p.261
conditions: The selected error metric significantly influences evolved results. Fair method comparisons require the same metrics/fabrication technology/synthesis tools/runtime/original circuit. # pp.258,260
