## summary
The document implements an on-chip RAM BIST state machine for the PowerPC 603 instruction/data caches and tag arrays (pp.388-391). The BIST runs a modified FA-13 memory-test algorithm on all four arrays in parallel and reports per-array failures through an IEEE 1149.1 interface (pp.390-393). The document does not establish an arithmetic-unit microarchitecture covered by this registry.
