## summary
The paper introduces a Variable Correction Truncated Multiplier that derives its correction from partial-product bits adjacent to the truncated LSB and injects those bits through array carry inputs (pp.1179-1180). The method reduces mean error/standard deviation relative to constant correction while retaining most of the truncated multiplier's gate savings (pp.1180-1182).

## families
### truncated_fixed_width  (role: extends)
mechanism: The multiplier discards low partial-product columns but retains k extra columns. The Variable Correction Truncated Multiplier uses the partial products in column n+k+1 as the correction value instead of adding one fixed constant. The partial-product AND-gate outputs enter the carry inputs of column n+k, which adds the correction without a separate correction adder. The correction becomes zero when the observed column contains no ONEs and increases with its ONE count. (p.1179)

errors_and_checks: Errors are measured against the full multiplier result in LSBs of the truncated multiplier (p.1181). Each tested correction value has mean-error magnitude below 0.5 LSB, and the aggregate mean error is approximately zero (p.1181). The exhaustive 8 by 8 experiment reports a distribution more evenly centered around zero than constant correction (p.1180). No fault model or concurrent checker is reported.
conditions: Truncation applies when multiplication results need not retain data-path LSB accuracy (pp.1178, 1182). Variable correction is intended when minimum error/maximized SNR matters or when several multiplications operate on one data sample (p.1182). Variable correction costs n-k-1 gates more than constant correction (p.1182). The constant-correction baseline assumes every input bit is equally likely to be ZERO or ONE (p.1179).
evidence: §1.0 and Figures 2-3 (pp.1178-1179); §2.0 and Figures 4-6 (pp.1179-1180); §§2.2-2.4, Table 3, Figure 8, and Table 4 (pp.1181-1182).
