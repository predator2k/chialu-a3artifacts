## summary
The paper proposes reduced precision redundancy (RPR), which detects voltage-overscaling errors in a main DSP datapath and substitutes the output of a reduced-precision replica. # p.497-498
The evaluated RPR systems protect FIR MAC and FFT butterfly computations while preserving their required output SNR. # p.503-507
The reported savings reach 60% for QPSK receive filtering and 44% for a WLAN OFDM FFT. # p.506-507

## families
### reduced_precision  (role: proposes)
mechanism: A voltage-overscaled main DSP and a shorter-delay reduced-precision replica compute concurrently. An error-control block compares their outputs against a threshold equal to the maximum error-free difference. The main output is selected within the threshold, and the replica output is substituted outside it. The replica must remain free of voltage-overscaling timing errors. # p.497-498
choices:
  bound_type: absolute   # p.498
  correct_by_substitution: true   # p.498
new_choices:
  decision_threshold_rule: maximum_error_free_difference — The threshold bounds the difference caused only by replica truncation. # p.498, p.505
  operating_point_search: joint_VOSF_and_replica_precision — A two-dimensional search minimizes power subject to noise-power and power constraints. # p.502
slots:
  none
parameters: The main and replica operand precisions are parameters, with the replica precision smaller than the main precision. # p.498-500 A studied MAC is 12×12 bits. # p.502 The filter is a 16-tap folded or unfolded FIR, and the unfolded form has one-cycle latency without throughput loss. # p.503, p.507 The FFT is a 64-point radix-2 DIT processor with 16-bit precision and 10-bit fixed-point complex inputs; one butterfly is computed per cycle. # p.503, p.507

errors_and_checks: The fault model is an input-dependent timing error caused when voltage overscaling makes an excited path slower than the sampling period. # p.497-500 The threshold rule guarantees no false alarm when the main output is error-free under the paper’s truncation assumptions. # p.498, p.509 Detected errors are corrected by replica substitution, while undetected errors remain residual noise. # p.498, p.509 The demonstrated application-level contract is preservation of the required output SNR through error rates of 0.09/sample for the FIR and 0.06/sample for the FFT. # p.507
conditions: RPR benefits from voltage-overscaling errors having large magnitudes and occurring for a small fraction of input combinations. # p.498 The replica critical path must remain below the sample period; the paper identifies ripple-carry adders and Baugh-Wooley multipliers as suitable because their delay decreases with precision. # p.498 The analysis ceases to apply when overscaling also causes replica errors. # p.501, p.507 Restricted FFT twiddle-factor operands reduce long-path excitation relative to a general-purpose multiplier. # p.505 Errors in the error-control block are outside the evaluated protection model. # p.508

## space_gaps
