## summary
The paper develops a very-high-radix square-root recurrence whose result digits are selected by rounding after residual prescaling. The architecture combines square root with prescaled division while preserving one cycle per division digit and using two cycles per square-root digit. A technology-independent comparison estimates speed-ups of 1.7 for division and 1.15 for square root against a Newton-Raphson unit. # p.827, p.829, p.840

## families
### digit_recurrence_sqrt_combined  (role: proposes)
mechanism: A factor M scales the square-root residual so that T[j] = MS[j] remains close to 1, which permits selection of s[j+1] by rounding a truncated carry-save residual. Each iteration computes v[j+1] = rw[j] - T[j]s[j+1] and then w[j+1] = v[j+1] - 0.5t[j+1]s[j+1]r^-J. The shared architecture divides this work across two square-root cycles and reuses its multipliers/converters for division. # p.828-p.829

### prescaled_very_high_radix  (role: instantiates)
mechanism: Division scales dividend x and divisor d by M, stores w[0] = Mx in carry-save form and the assimilated scaled divisor z = Md, selects q[j+1] by rounding the shifted residual, and updates w[j+1] = rw[j] - q[j+1]z. The combined unit computes M by table-provided linear-interpolation coefficients and a carry-save multiply/accumulate path. # p.829, p.832-p.837

## space_gaps
* `digit_recurrence_sqrt_combined.radix` needs value 512 for the proposed very-high-radix design. # p.834-p.835
* `digit_recurrence_sqrt_combined.slot digit_select` needs a rounding/recoding implementation rather than only `qds_table`. # p.828-p.829
* Both combined recurrence families need choices for residual prescaling, result-digit selection, and cycles per iteration. # p.828-p.829
* `prescaled_very_high_radix` needs a slot for the table-plus-linear-interpolation scaling-factor generator. # p.832-p.834

## open_questions
* The supplied text does not expose the individual cell values in Tables 2-6, so the exact proposed per-radix cycle/time/area estimates must not be reconstructed.
* The paper calls MUL/L-MUL/MAC carry-save multipliers with radix-4 recoding, but the text does not settle which multiplier family fills the prescaler slot.
