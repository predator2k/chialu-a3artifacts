## summary
The article presents Sanity-Check, which embeds spatial and temporal linear invariants into fully connected and convolutional DNN layers for concurrent error detection (pp.27-30). The article proves detection guarantees, gives software/hardware implementation guidance, reports AlexNet and systolic-array results, and surveys linear-checksum extensions across GPUs/FPGAs/IMC systems (pp.30-39).

## families
### abft_checksum  (role: extends)
mechanism: Spatial checksums add a sanity neuron/filter whose weights and bias are additive inverses of the original values, so outputs sum to zero across neurons or filters. Temporal checksums accumulate an input batch and append its additive inverse, so output accumulation equals a bias-dependent constant. Software checks sum-reduce outputs; dedicated hardware adds a MAC-array column, an adder row, sanity-input generators, check accumulators, and constant comparators. Floating-point checks use profiled layer-specific thresholds instead of exact equality. (pp.27-33)

errors_and_checks: Temporal checksums guarantee detection of a single input error; spatial checksums guarantee detection of a single weight/filter or bias error; either checksum detects a single output/computation error; both checksums guarantee detection of three or fewer output/computation errors. A single output error is correctable, but some triple-error signatures can cause miscorrection, so Sanity-Check forgoes correction. Thresholds from 2× to 100× the maximum training-set deviation retain perfect error-caused misprediction detection, and the initial threshold produces no false alarms in the experiment. (pp.30-31, pp.34-35)
conditions: Spatial checksums cannot detect input errors, and temporal checksums cannot detect weight errors, so both are needed for their combined coverage (p.30). Floating-point implementations require layer-specific profiled thresholds because round-off prevents exact equality checks (pp.31-32). Full-width fixed-point multiplication/accumulation can avoid round-off if truncation occurs only after the layer, while residue arithmetic can remove round-off from checksum calculations (pp.32-33). Temporal checksums reduce throughput by N/(N+1) because each batch requires one extra prediction (p.33). Checksums apply directly to linear subsystems; nonlinear stages require supplementary methods (pp.38-39).
evidence: Equations (1)-(13) and Figures 1-3 (pp.27-33); Lemmas 1-6 (pp.30-31); Figure 4 and Tables 1-2 (pp.34-35); survey sections (pp.35-39).

## space_gaps
* `abft_checksum` lacks values for spatial/temporal checksum dimensions and for combining both dimensions (pp.27-30).
* `abft_checksum` lacks an invariant-embedding choice covering extra neuron/filter parameters and additive-inverse temporal inputs (pp.28-30).
* `abft_checksum` lacks an exact-versus-thresholded comparison choice for finite-precision arithmetic (pp.31-32).
* `abft_checksum` lacks recovery modes for weighted-checksum correction, replay, spare-MAC replacement, and staged multischeme recovery surveyed in the article (pp.36-37).
* `duplication.comparison_point` lacks DNN-specific prediction and likelihood-vector comparison values (p.33).
