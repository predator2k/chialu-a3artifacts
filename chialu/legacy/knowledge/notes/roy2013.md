## summary
The paper proposes bottom-up synthesis of parallel-prefix graphs that minimize prefix-node count under bitwise logic-level/fanout/wire-length/arrival-time constraints. Compact graph encoding, lazy copying, and pruning scale the search to 128-bit adders while retaining multiple candidate structures. Post-placement results report better timing/area than Brent-Kung/Kogge-Stone/dynamic-programming/full-custom baselines.

## families
### prefix_synthesis_nonuniform_arrival  (role: proposes)
mechanism: Binary addition is mapped to associative prefix computation of group generate/propagate signals. The algorithm constructs all candidate n+1-bit graphs from retained n-bit graphs by inserting the new index in valid topological positions. A packed integer stores each node’s MSB/LSB/level/fanout. Lazy copying and level/dynamic-size/repeatability/structure pruning reduce memory/runtime. Candidate graphs minimize prefix-node count subject to bitwise level constraints and optional fanout/wire-length/arrival/required-time constraints; multiple minimum or Pareto-relevant solutions remain available for physical evaluation.

conditions: Prefix-node count is a technology-independent area measure, while node logic level only roughly estimates timing because fanout distribution and graph size also affect physical timing. Smaller graphs provide more gate-sizing flexibility, but higher node count with lower maximum fanout can improve post-placement timing. Vth swapping is disabled, so leakage is assumed proportional to area. The method targets high-performance minimum-level adders and requires pruning parameters large enough to retain feasible graphs under structural constraints.   # pp.2,4,6,8
evidence: §§2-3; Algorithms 1; Tables 1-6; Figures 2-11; post-placement discussion on pp.6-8

## space_gaps
* `arrival_profile` lacks arbitrary per-bit arrival/required-time constraints, which are central to the synthesis method.   # pp.1,6,8
* `search_method` lacks exhaustive bottom-up enumeration with level/size/repeatability/structure pruning.   # pp.3-5
* `prefix_synthesis_nonuniform_arrival` lacks a wire-length constraint choice.   # p.1
* `prefix_synthesis_nonuniform_arrival` lacks choices for retaining multiple optimal candidates and explicit prefix-node-count minimization.   # pp.1,6-7

## open_questions
* The “cutting-edge technology node” used for mapping and placement is not identified.   # p.6
* The paper calls area/wire length unitless while describing them as numbers of icells/tracks.   # p.6
* The absolute critical-path delays used for the reported 64-bit percentage improvements are not printed.   # p.7
