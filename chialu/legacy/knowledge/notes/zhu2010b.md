## summary
The document proposes ETAII, which divides a binary adder into concurrent short carry-propagation blocks and accepts occasional incorrect interblock carries. ETAIIM cascades selected carry generators so higher-order blocks use longer prediction windows. A 32-bit, 4-bit-per-block implementation is compared with ETAI/RCA/CSK/CSL/CLA designs.

## families
### segmented_carry_speculative  (role: proposes)
mechanism: ETAII divides an N-bit adder into M blocks of N/M bits. Each block has a carry generator that ignores the preceding block carry and a sum generator that accepts that carry, so carry propagation is limited to two neighboring blocks and the stated longest path is 2N/M bits. ETAIIM cascades the first three carry generators so the two highest blocks derive carries from the preceding 12 and 8 bits. (pp.70-71)
