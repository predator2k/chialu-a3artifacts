## summary
NN-LUT transforms a trained one-hidden-layer ReLU approximation network into an equivalent piecewise-linear LUT with adjustable breakpoints and one multiply-add evaluation path. The same 16-entry hardware approximates GELU, EXP, DIV, and 1/SQRT for Transformer inference. # p.2-5

## families
### transformer_activation_lut  (role: proposes)
mechanism: A one-hidden-layer ReLU network with N−1 neurons is trained offline against a target function. The trained weights and biases define N−1 sorted breakpoints and N interval-specific linear functions `s_i x + t_i`, which are stored as an N-entry LUT. At inference, a comparator selects the interval, the LUT supplies `s_i` and `t_i`, and a multiplier plus adder produces the approximation. The LUT contents can be replaced for GELU, EXP, DIV, or 1/SQRT without changing the datapath. # p.2-5
choices:
  method: learned_lut_pwl  # p.2-3
  operand_format: fp16; fp32 [outside domain]; int32 [outside domain]  # p.4-5
  calibration: learned_from_data  # p.3-4
new_choices:
  lut_entries: 16 — number of stored piecewise-linear intervals and parameter pairs  # p.4
  parameter_precision: {INT32, FP16, FP32} — precision of breakpoints, slopes, intercepts, and computing units  # p.4-5
  input_scaling: power_of_two — maps small 1/SQRT inputs into the trained range with shifts  # p.3
  post_training_calibration: unlabeled_activation_regression — recalibrates each NN-LUT while Transformer parameters remain frozen  # p.3-4
slots:
  segmenter: nonuniform [addressing=comparator_tree, boundary_search=neural_network_training [outside domain]]  # p.2-3, p.5
parameters: 16 entries; N−1 ReLU neurons for N intervals; targets GELU/EXP/DIV/1/SQRT; two-cycle lookup and computation; training dataset size 100K; calibration uses one-tenth of the training dataset for five epochs  # p.2-5

errors_and_checks: Approximation quality is evaluated with operation-wise L1 error and downstream GLUE/SQuAD accuracy. No maximum-ulp, maximum-absolute-error, or formal error bound is reported. Direct FP32/FP16 NN-LUT Softmax loses 0.0 SQuAD F1, while calibration improves average GLUE accuracy for FP32 and INT32 variants. # p.4
conditions: Adjustable breakpoints matter most for Softmax and LayerNorm functions with large dynamic ranges. A power-of-two input scale is required for small 1/SQRT inputs. Sixteen entries are reported as sufficient in the evaluated models. Calibration uses unlabeled data and takes less than 5% of fine-tuning time. Existing NPUs with LUTs and arithmetic units may incur little additional hardware cost. # p.3-5
