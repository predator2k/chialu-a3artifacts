## summary
The paper proposes a decimal floating-point fused multiply-add architecture that retains a [–8, 7] redundant encoding through multiplication, addition, and post-alignment. The final rounder combines digit-set conversion, absolute-value conversion, and rounding into one carry-propagation process. The synthesized combinational design has 3.92 ns delay and 315,825 um2 area in an STM-90 nm library.

### redundant_decimal_post_alignment  (domain: decimal: decimal misc, closest: decimal_fma, why_not: the vocabulary has no reusable family for signed-digit post-alignment, leading-position correction, and signed-sticky generation)
mechanism: The post-alignment unit selects among five shift cases using the preferred/temporary exponent difference, the leading non-zero position, and the trailing-zero count. A pattern-detection tree corrects the possible one-digit leading-position error. A prefix tree classifies shifted-out redundant digits as positive/zero/negative and supplies a two-bit signed sticky value. # pp.150–154

## space_gaps
* `decimal_fma` lacks slots for its significand adder, pre-alignment, post-alignment, and rounder, which Fig. 1 names as architectural sub-modules.  # p.148
* `parallel_decimal_multiplication.internal_digit_code` lacks the 4-bit two’s-complement signed-digit [–8, 7] encoding.  # pp.148–149
* `redundant_decimal_addition.digit_set` lacks [–8, 7] and does not represent different input/output digit sets.  # p.149
* `parallel_decimal_multiplication.reduction_tree` lacks a documented value for the redundant decimal PPR network.  # pp.148–149

## open_questions
* The performance section specifies a 16-digit result and cites a `d64` verification package, but it does not explicitly name the synthesized configuration as IEEE decimal64.
* Table 7 prints `48,468` in the [20] multiplier-tree delay column, which is inconsistent with the FO4 values used elsewhere and is therefore omitted.
* The paper does not state pipeline depth, initiation interval, or registered latency because only combinational logic is synthesized.
* The 425599 directed vectors and 50 K random vectors do not establish an exhaustive IEEE conformance or correct-rounding proof.
