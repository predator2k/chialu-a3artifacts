## summary
The document proposes ESHA, a softmax unit that replaces division with logarithmic-domain subtraction and varies exponential accuracy according to the separation between input values. The design combines maximum-based preprocessing, a group lookup table exponential unit, an equal-interval Maclaurin logarithm unit, and a pipelined datapath. ESHA reports 99.01% MNIST classification accuracy and 500 MHz synthesis at 65nm. # p.75, pp.77-80

## families
### softmax_layernorm  (role: proposes)
mechanism: ESHA subtracts the maximum input, retains values in [Maximum-8, Maximum], maps retained values into [-4, 4], evaluates exponentials, sums them, evaluates the natural logarithm of the sum, subtracts that logarithm from each shifted input, and applies a final exponential. CFIFO/PFIFO structures retain the positions/values of valid inputs. A single valid input bypasses subsequent calculations and produces probability 100%. # pp.76-77

### lut_plus_poly  (role: extends)
mechanism: The logarithm unit selects a stored reference R and evaluates ln(x) as lnR plus a two-term Maclaurin approximation of ln[1+(x-R)/R]. Equal LUT intervals replace the prior non-equal intervals to reduce accuracy variation and LUT use. The datapath contains address decoding/LUTs, difference generation, multiplication for the squared term, subtraction, and final addition. # pp.76-78

## new_families
### grouped_lut_exponential  (domain: sfu: elementary-function units, closest: compressed_lut, why_not: the input is decomposed into groups whose exponential values are multiplied, rather than stored with a compressed value encoding)
mechanism: The input is decomposed as x=x1+x2+x3, so exp(x) is evaluated as exp(x1)×exp(x2)×exp(x3). Each component addresses a LUT whose data is grouped in four-bit units. Enable signals activate zero to three LUTs sequentially according to input proximity, which trades multipliers/LUT activity for calculation accuracy. All three LUTs provide a 25-bit binary fraction. # p.77

## space_gaps
* `softmax_layernorm.exp_evaluation` needs a `group_lookup_table` value for multiplicatively composed exponential tables. # p.77
* `softmax_layernorm` lacks slots for the exponential and logarithmic function units that determine ESHA accuracy/resource use. # pp.76-79
* `softmax_layernorm` lacks a choice for data-dependent accuracy/resource selection. # pp.77-79
* The elementary-function vocabulary lacks a grouped multiplicative LUT exponential family. # p.77

## open_questions

* The document does not report overall latency, initiation interval, ASIC voltage, process corner, or switching assumptions. # pp.79-80
* The document does not quantify how often each zero-, one-, two-, or three-LUT accuracy mode occurs on the evaluated workload. # pp.77-79
