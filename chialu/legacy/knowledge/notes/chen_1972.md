## summary
The document proposes a unified shift/add/table/bit-counting apparatus for exponentials, logarithms, ratios, and inverse square roots. A data-dependent cotransformation removes leading significant bits before a linear termination step completes the result in about one conventional multiply time.

## families
### digit_recurrence_exp_log  (role: extends)
mechanism: The exponential recurrence subtracts ln(1 + 2^-m) from x and multiplies y by 1 + 2^-m. The logarithm recurrence multiplies x by 1 + 2^-m and subtracts the same table value from y. Sequential bit counting selects m from the leading one in x or 1-x, so zero bit positions require no iterations. Linear extrapolation terminates after roughly half the fraction bits have been cleared. # pp. 382-385

errors_and_checks: For exponential termination, 0 < ε ≤ μ²/2(1 + 2μ/3). For logarithm termination, the absolute error is approximately -μ²/2. With J guard bits, the iteration rounding-error bound is p ≤ i(j+k); the paper states that J=6 ensures p ≤ 2^-(N+1) for N≤64 with rounded arithmetic or N≤32 with unrounded arithmetic. No algorithm failure was found in the APL simulations.   # pp.382, 384, 386
conditions: Exponential inputs use 0≤x<ln 2, while logarithm inputs use 1/2≤x<1. The algorithms can accept 0<x<1 with potentially slower convergence. The implementation requires special guard bits and has variable timing.   # pp.382, 386

## new_families
### bit_counted_cotransformation  (domain: sfu: elementary-function units, closest: digit_recurrence_exp_log, why_not: digit_recurrence_exp_log does not cover the same invariant-pair recurrence for ratios/inverse square roots or its data-dependent bit-skipping and terminal extrapolation)
mechanism: A pair (x,y) is transformed while F(x,y) remains invariant. Each iteration chooses a_k=(1+2^-m) or its function-specific power, where m comes from the leading significant bit of |x-x_w|. Shift/add operations move x toward its known goal and move y toward the result. Exponential/logarithm use a shared table of -ln(1+2^-m); ratio/inverse-square-root require no such y-table update. A final linear approximation uses the small residual μ and an abbreviated multiply. # pp.381-385
choices:
  function_set: {exponential, logarithm, ratio, inverse_square_root}   # p.382
  m_selection: {leading_zeros, leading_ones}   # p.384

  constant_table: {ln_one_plus_pow2, none}   # pp.383, 385
  shared_apparatus: Bool   # p.385
