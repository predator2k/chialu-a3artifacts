## summary
The document presents table-driven IEEE 754 single- and double-precision implementations of exp using argument reduction, a local Remez polynomial, and a 32-entry split-value reconstruction table. The proved error is below 0.54 ulp without underflow and no worse than 0.77 ulp with gradual underflow, using only working-precision arithmetic.

## families
### lut_plus_poly  (role: proposes)
mechanism: The input X is reduced as X = (32M + J)log 2/32 + (R1 + R2), with J selecting one of 32 precomputed values 2^(J/32). A polynomial approximates exp(R1 + R2) - 1, and reconstruction computes 2^M times the selected table value plus its polynomial correction. Each table value is split into S-lead(J) and S-trail(J), whose sum has roughly twice working precision. # pp.146-148

### range_reduction  (role: instantiates)
