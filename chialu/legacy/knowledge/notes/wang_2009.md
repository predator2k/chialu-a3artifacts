## summary
The paper proposes an IEEE 754-2008 decimal64 adder that combines parallel decimal alignment, injection-based rounding, and a modified Kogge-Stone network with flag-based postcorrection and trailing-nine detection (pp.322, 326-331). The paper extends the adder into an eight-operation decimal floating-point multifunction unit with six pipeline stages and one-result-per-cycle throughput (pp.322, 331-333).

## families
### decimal_fp_addition  (role: proposes)
mechanism: DPD operands are converted to BCD, swapped by exponent order, and aligned with parallel left/right decimal barrel shifters. A rounding-dependent value is injected before a modified Kogge-Stone significand addition. Postcorrection restores BCD, while flag vectors perform increment/trailing-nine handling without another carry-propagate addition. The result is truncated, encoded back to DPD, and replaced with special values when required. (pp.326-331)
choices:

  leading_zero_anticipation: false   # pp.326-327
  format: decimal64   # pp.322, 326
new_choices:
  alignment_execution: parallel_left_and_right — computes LSA/RSA and shifts both significands to establish a fixed rounding position   # pp.326-328
  rounding_carry_avoidance: trailing_nine_flag_vectors — uses F2 to conditionally increment after an MSD shift without another carry-propagate addition   # pp.329-330
slots:
  significand_adder: speculative_decimal_addition   # pp.328-330
parameters: 64-bit decimal64 operands; p = 16 digits; aligned path includes 16 significand digits plus guard/round/sticky digits; 19-digit operands enter the K-S network   # pp.322, 326-329

### speculative_decimal_addition  (role: proposes)

## space_gaps
* `decimal_fp_addition.alignment` lacks a value for the parallel dual-shifter alignment that left-shifts one significand while right-shifting the other from LSA/RSA.   # pp.326-328
* No existing family represents an adder-derived DFP multifunction unit that implements eight IEEE 754-2008 operations through shared alignment/significand/exception hardware.   # pp.331-333
* `parallel_prefix` lacks choices for flag-vector outputs used for decimal postcorrection and trailing-nine rounding.   # pp.328-330
