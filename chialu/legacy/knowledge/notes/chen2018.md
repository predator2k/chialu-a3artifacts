## summary
The paper proposes approximate radix-4/radix-8 SRT array dividers that replace or truncate binary signed-digit adder cells and optionally add a three-cell error-compensation cluster. The designs trade accuracy for power/area and reduce delay relative to a radix-2 restoring approximate divider, with image change-detection/scaling used as applications. # p.1, p.5-13

## families
### approximate_recurrence  (role: proposes)
mechanism: A prescaled high-radix SRT array represents each partial remainder with carry-free binary signed digits. Approximation replaces selected EXSDAC cells with AXSDAC cells or eliminates cells by truncation. Vertical/horizontal/square/triangle geometries control which rows and columns are approximated. A cluster containing an EXSDAC, AXSDAC and eight-transistor ECPLC buffers truncation errors near quotient-generating residual bits. # p.3-6

### srt_high_radix  (role: instantiates)
mechanism: The divider uses the SRT recurrence R(j+1)=rR(j)-q(j+1)D with r=2^m and quotient digits from {-(r-1),...,r-1}. Prescaling places D in a restricted interval, after which the integer part of the shifted partial remainder directly supplies the next quotient digit. The implementation uses a fully combinational array rather than a quotient-digit lookup table. # p.2-4

slots:
  digit_select: none   # p.2-4
parameters: 1/2 ≤ X < D < 1 before prescaling; r=2^m; t fractional digits converted for selection; ceil(n/m) recurrence steps   # p.3

### generalized_signed_digit  (role: instantiates)
mechanism: Binary signed digits from {-1,0,1} encode each partial remainder as positive/negative flag pairs. Carry-free signed-digit adder rows update the residual, while digit-serial on-the-fly conversion produces a conventional two's-complement quotient without a terminal addition. # p.3-4

## space_gaps
* `approximate_recurrence.replaced_depth` excludes odd d values, although d=1 and d=3 are evaluated. # p.11
* `approximate_recurrence` lacks choices for replacement/truncation/error-compensation action and vertical/horizontal/square/triangle placement. # p.5-6
* `srt_high_radix` permits only `qds_table` in `digit_select`, while this design uses prescaling and direct integer-part quotient selection without a table. # p.2-4
* `generalized_signed_digit.digit_encoding` lacks the positive/negative flag-pair encoding used for BSD digits. # p.4
* `error_analysis_quality.metric` lacks NED and NPP, which are the paper's principal accuracy and accuracy-power metrics. # p.6, p.10

## open_questions
* The extracted figure text does not preserve numeric plot axes, so absolute NED/power/area/delay values must not be inferred from Figs. 10-35.
* The paper does not state whether every NED/error-distribution simulation exhaustively enumerates the valid input space.
* The paper does not report a worst-case quotient-error bound or a formal application-accuracy contract.
