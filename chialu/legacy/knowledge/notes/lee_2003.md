## summary
The document proposes a fixed-point first-order polynomial function evaluator with non-uniform segments addressed by prefix circuits. Independent power-of-two coefficient scaling trades precision for multiplier/adder range. FPGA implementations evaluate √−ln(x), cos(2πx), and sin(2πx) for Gaussian noise generation.

## families
### pwl  (role: proposes)
mechanism: Each segment stores coefficients for the minimax line p(x) = c1 × x + c0. A ROM supplies c1/c0 and independent scaling factors; the datapath multiplies c1 by x, scales both terms by powers of two, and adds them. The segment-address calculator, multiplier, and adder can be pipelined. # p.797, p.800

### nonuniform  (role: proposes)
mechanism: Segment widths follow local linearity. Widths grow or shrink by factors of two or more, so cascaded OR/AND prefix circuits count leading zeros/ones and feed an adder that produces the segment address. Uniform intervals may contain non-uniform inner segments, and selected cascade taps determine the available boundaries. # p.798-p.800
choices:
  addressing: power_of_two_cascade   # p.799
  boundary_search: manual [outside domain]   # p.800, p.802
new_choices:
  segment_growth_factor: factor of two or more — controls successive segment widths and selected prefix taps   # p.798-p.799
  nesting: uniform or non-uniform intervals containing uniform or non-uniform segments — extends boundary placement flexibility   # p.800
slots:
  none
parameters: The 8-bit illustrative address circuit produces up to 14 segment addresses. The implemented √−ln(x) partition has 59 segments; the cos(2πx) partition has four uniform intervals and 21 total segments.   # p.799, p.803-p.804

## space_gaps
* `pwl` lacks independent coefficient-scaling and per-coefficient-width choices for c1/cs1/c0/cs0. # p.800, p.805
* `nonuniform.boundary_search` lacks the manually selected local-linearity method used by the implementations. # p.800, p.803-p.804
* `nonuniform` lacks choices for factor-of-two-or-more segment progression and nested uniform/non-uniform partitions. # p.798-p.800

## open_questions
* The document does not state the signedness or exact integer/fraction partition for every coefficient and intermediate datapath.
* The document reports 14 pipeline cycles but does not specify the exact register placement or latency contribution of each architectural block.
* The document includes sin(2πx) in the implementation and total ROM size but does not report its segment count or coefficient widths separately.
