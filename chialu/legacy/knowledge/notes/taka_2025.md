## summary
The document proposes 4×4 systolic sparse tensor slices that execute dense, 2:4, 1:3, and 1:4 structured-sparse GEMM in FPGA fabric. The slices support int8-to-int32 and bfloat16-to-fp32 MACs, dedicated vertical interconnects, and dynamic sparsity selection. Modeled accelerators reach 100% processing-element utilization and up to 3.52× application speedup over dense in-fabric acceleration.

## families
### ai_tensor_block  (role: extends)
mechanism: Each SST slice contains a 4×4 output-stationary array of 16 sparse processing elements. Matrix A values and 2-bit indices move horizontally, while four candidate B values move vertically; an index-controlled 4:1 multiplexer selects each product operand. Pipeline staging retains B values for two cycles in 2:4 mode and reloads them each cycle in 1:3/1:4 modes. Dedicated vertical wires cascade adjacent slices, and a six-register buffer converts diagonal completion into four column-wise outputs per cycle. Dynamic controls select int8/bfloat16 and dense/2:4/1:3/1:4 operation. # pp.3–5

conditions: SST acceleration assumes static structured sparsity in matrix A/weights and dense matrix B/activations. Every supported mode maintains 100% SPE utilization; 2:4, 1:3, and 1:4 provide 2×, 3×, and 4× compute speedup over dense operation. GEMM dimensions M′ and N′ must be multiples of Y·4 and X·4, while K′ is unrestricted. Sparsity above 90% may favor unstructured CLB/DSP accelerators, and dynamic activation sparsity is not supported. # pp.4–5,10
