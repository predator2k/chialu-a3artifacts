## summary
The chapter defines self-testing/fault-secure/totally self-checking combinational circuits and extends the framework to strongly fault-secure/code-disjoint and ultimate fail-safe designs. It presents encoding-based elimination of bidirectional errors, self-dual parity checking, mod-3 residue checking, and coded PLA implementations.   # p.60-93

## families
### self_checking_datapath  (role: defines)
mechanism: A functional circuit maps input code words to output code words, while a checker validates the output code. A non-code output signals a fault in the functional circuit or checker, but the checker output does not locate which circuit contains the fault.

### residue  (role: instantiates)
mechanism: The low-cost residue scheme appends the two-bit mod-3 residue of the functional output. One generator predicts the residue from the inputs, another generates its complement from the output, and a two-rail comparator tests whether the residues are complementary.

## open_questions
* The chapter does not quantify which multibit error patterns the mod-3 residue schemes detect beyond examples and “the majority” or “a significant portion.”   # p.83, p.89-90
* The chapter does not specify the internal implementation of the two-rail checker because that material is deferred to Chapter 4.   # p.84
* The chapter does not quantify hardware overhead for the self-dual complement circuit.   # p.82
