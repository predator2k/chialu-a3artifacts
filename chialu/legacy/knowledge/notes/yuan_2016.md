## summary
The document proposes a softmax architecture that replaces division with logarithmic-domain subtraction and subtracts the maximum inner product before exponentiation. The transformed architecture bounds exponential outputs to [0, 1], reduces the logarithmic-unit input range to [0, N], and produces logarithmic scores for category ranking. No implementation measurements or numerical error bounds are reported.

### softmax_layernorm  (role: proposes)
mechanism: The architecture computes ln(Pr(m)) as `(Wm•A - (W•A)max) - ln(ΣL=1N e^(WL•A-(W•A)max))`. A shared sorting block finds `(W•A)max`; N exponential units process shifted inner products; an adder tree and one LOG unit form the shared normalization term; and 2N subtractors replace N dividers. The final exponential conversion is omitted because the neuron outputs are used only for magnitude ranking. # p.325
