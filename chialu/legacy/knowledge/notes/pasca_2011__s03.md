## summary
The chapter describes the arithmetic resources of Xilinx and Altera FPGAs from 2004 through 2011, including LUT-based logic, dedicated carry chains, DSP blocks, and block memories. The chapter settles device-specific carry-chain boundaries, DSP multiplier widths, arithmetic modes, cascade paths, and pipeline capacity. The chapter reports architectural capacities rather than measured arithmetic latency/area results.

## families
### fpga_carry_chain  (role: compares)
mechanism: Xilinx slices and Altera ALMs implement ripple-carry adders with dedicated fast carry lines rather than the general routing network. Xilinx carry lines traverse vertically across CLBs. Altera carry chains remain within a LAB, so wider additions incur inter-LAB routing delay.   # p.25, p.26

### dsp48_style_slice  (role: taxonomizes)
mechanism: Virtex-4 DSP48 contains an 18x18-bit two's-complement multiplier followed by a 48-bit sign-extended three-operand adder/subtracter or accumulator. The multiplier supplies two 36-bit-aligned subproducts to the adder. Direct PCIN/PCOUT and BCIN/BCOUT paths support neighboring-block cascades, and PCIN can be shifted right by 17 bits. DSP48E and DSP48E1 enlarge the multiplier to 18x25 bits and add logic/pattern-detection operations; DSP48E1 also adds premultiplication adders.   # p.28
choices:
  mult_shape: 18x18; 25x18   # p.28
  pre_adder: false (DSP48/DSP48E); true (DSP48E1)   # p.28
  alu_width: 48   # p.28
  alu_op_set: add_sub (DSP48); add_sub_logic (DSP48E/DSP48E1)   # p.28
  simd_partition: UNKNOWN   # p.28
  pattern_detector: false (DSP48); true (DSP48E/DSP48E1)   # p.28
  cascade_paths: result_and_operand   # p.28
new_choices:
  cascade_shift: {none, shift_right_17} — fixed alignment applied to the PCIN result cascade   # p.28
  pipeline_register_levels: Int[0..4:1] — number of internal pipeline-register levels used   # p.28

  multiplier: UNKNOWN   # p.28

### variable_precision_dsp  (role: instantiates)
mechanism: A Stratix-II DSP block combines four 18x18-bit multipliers with a flexible adder tree. Stratix-III/-IV divide the block into two largely independent half-DSPs and roughly double multiplier density. The configurable multiplier array supports independent products, two-product sums, four-product sums, and a 36x36-bit multiplication mode. Neighboring accumulator units can receive cascaded half-DSP outputs.   # p.28, p.29, p.30

## space_gaps
* `fpga_carry_chain.chain_segment_length` excludes the 20-bit LAB-local chain reported for Stratix-III/-IV.   # p.26
* `variable_precision_dsp.native_widths` lacks the reported 9/12/18/36-bit width combination.   # p.30
* `dsp48_style_slice` lacks choices for the fixed 17-bit result-cascade shift and internal pipeline-register depth.   # p.28
* `variable_precision_dsp` lacks choices for independent/two-product/four-product adder modes and whole-DSP/half-DSP partitioning.   # p.29, p.30
* `dsp48_style_slice.alu_adder` cannot describe the hard three-operand adder without assigning an unsupported carry-propagate microarchitecture.   # p.28

## open_questions
* The chapter does not disclose the internal multiplier or adder microarchitecture of either vendor's DSP blocks.   # p.28, p.29
* The chapter does not state a fixed Xilinx carry-chain segment length or the delay of crossing Xilinx CLB boundaries.   # p.25
