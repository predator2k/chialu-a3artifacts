## summary
ETAIV divides an N-bit adder into short blocks and uses a Type I carry generator to select between two concurrently evaluated Type II carry generators, which improves ETAII accuracy without extending the speculative carry path (pp.324-325). A 32-bit ETAIV is evaluated for accuracy, power, delay, PDP, transistor count, and DSP sound processing (pp.325-327).

## families
### segmented_carry_speculative  (role: extends)
mechanism: ETAIV divides an N-bit addition into N/X sum-generator blocks. X-bit Type I and Type II carry generators operate concurrently. Each Type II generator evaluates one assumed carry input, and a 2-to-1 multiplexer uses the Type I output to select the carry supplied to the most-significant sum-generator block. The selected dual-generator structure increases the accuracy of the predicted carry without adding a serial carry-generation stage. (pp.324-325)

## open_questions

* The text does not settle whether `sub_adder` should be recorded as `ripple_carry`, `carry_lookahead`, or a heterogeneous combination.
* The circuit simulations do not state supply voltage, input transition assumptions, or the exact definition/unit of “PDP × Transistor count.”
