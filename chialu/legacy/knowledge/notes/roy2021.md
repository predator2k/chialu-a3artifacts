## summary
PrefixRL constructs legal parallel-prefix circuits through scalarized Double-DQN reinforcement learning with synthesized area/delay feedback. The generated 32b and 64b prefix adders Pareto-dominate the evaluated regular/search-generated baselines under OpenPhySyn and Nangate45, with maximum same-delay area savings of 16.0% and 30.2%, respectively. Adders trained with open-source tools also transfer to an undisclosed industrial 8nm flow.

## families
### prefix_synthesis_nonuniform_arrival  (role: proposes)
mechanism: PrefixRL represents an N-input prefix graph as an N × N grid and permits add/delete actions at non-input/output node locations. A legalization procedure inserts missing lower-parent nodes after each action, so every visited graph remains legal. Scalarized Double-DQN agents learn separate area/delay Q values and select actions using weighted combinations of those values. Physical synthesis at four timing targets supplies the training reward, and multiple scalarization weights generate an area-delay Pareto frontier. # pp.854-856
