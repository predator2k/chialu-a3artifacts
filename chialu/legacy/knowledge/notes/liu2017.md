## summary
The paper proposes R4ABM1/R4ABM2 signed approximate radix-4 Booth multipliers using approximate Booth encoders in the least-significant partial-product columns, a regularized partial-product array, exact 4-2 compression, and an exact CLA final adder (pp.2-4). The approximation factor p controls the power/accuracy tradeoff, and R4ABM2 with p=14 provides the reported best PDP/NMED tradeoff among the compared 16-bit designs (pp.4,7).

## families
### booth_recoded_parallel  (role: extends)
mechanism: An N-bit two's-complement multiplier uses radix-4 modified Booth encoding to select -2A, -A, 0, A, or 2A and halve the number of partial-product rows. R4ABM1/R4ABM2 replace encoding only in the p least-significant partial-product columns. Exact MBE remains in the 2N-p most-significant columns. Exact 4-2 compressors reduce the partial products, and an exact carry-lookahead adder produces the final product. The highest-row Neg term is ignored to regularize the array and save one reduction stage (pp.2-4).
choices:
  booth_radix: 4   # p.2
  negative_pp_encoding: ones_complement_plus_neg_bit   # p.3
  hard_multiple_gen: none   # p.2
new_choices:
  approximate_encoder_region: p least-significant partial-product columns — selects which columns use approximate rather than exact MBE   # p.4
  regular_array_neg_handling: ignore the Neg term in row N/2+1 — regularizes the array and saves one reduction stage   # p.4
slots:
  reduction: compressor_4_2_tree   # p.4
parameters: N-bit signed two's-complement operands; evaluated at N=8, 16, and 32; combinational implementation; p=1, 2, ..., 2N   # pp.2,4,6

errors_and_checks: The multiplier is intentionally inexact and has no error compensation or recovery. NMED/ER are 0.9303×10^-5/93.75% for 16-bit R4ABM1 at p=14 and 0.6243×10^-5/99.61% for 16-bit R4ABM2 at p=14 (pp.5,7).
conditions: Approximate-encoder delay affects the multiplier critical path only for p>6; for p<7, delay improvement comes only from the regular partial-product array (p.4). R4ABM2 generally reduces power/delay/area/PDP more than R4ABM1, while increasing error rate at the same p (pp.5-6).
evidence: §2.1-2.5, Fig. 2, Tables 5-8 (pp.2-7).

### approximate_booth  (role: proposes)
mechanism: R4ABE1 changes four Booth-encoder truth-table entries from 1 to 0, producing ppij=(b2i XOR b2i-1)(b2i+1 XOR aj). R4ABE2 changes eight entries in both directions and reduces the output to ppij=b2i+1 XOR aj. R4ABM1/R4ABM2 apply the corresponding encoder to the p least-significant partial-product columns. R4ABE1 produces one-directional magnitude errors, while R4ABE2 produces positive and negative errors that can complement during reduction (pp.3-5).
choices:
  radix: 4   # p.2
  approx_encoder_columns: p=1, 2, ..., 2N [outside domain]   # p.4
  encoder: abe1; abe2   # pp.3-4
new_choices:
  encoder_error_polarity: magnitude-reducing_only; bidirectional — distinguishes R4ABE1 from R4ABE2 error behavior   # pp.3-5
  regular_partial_product_array: ignored highest-row Neg term — removes one reduction stage   # p.4
slots:
  none
parameters: R4ABE1 uses two XOR-2 gates and one AND-2 gate; R4ABE2 uses one XOR-2 gate; R4ABM1/R4ABM2 use N=8, 16, or 32 and variable p   # pp.3-6

## space_gaps
* approximate_booth lacks reduction-tree and final-adder slots, although this design fixes them as exact 4-2 compression and an exact carry-lookahead adder (p.4).
* approximate_booth.approx_encoder_columns does not cover the document's p=1,...,2N definition or evaluated p values above 16 for 16-/32-bit multipliers (pp.4,6).
* approximate_booth needs a regular-array Neg-handling choice because ignoring the highest-row Neg term independently changes error and reduction depth (p.4).

## open_questions
* The paper defines every integer p from 1 through 2N, but its evaluation tables report selected even values, so hardware results for odd p remain unspecified.
* The final CLA topology/grouping and the exact 4-2 compressor implementation are not specified.
