## summary
The paper proposes automated hierarchical segmentation for fixed-point hardware function evaluation using piecewise degree-1/degree-2 polynomials. The hierarchy combines uniform segments with segments whose sizes vary by powers of two, which reduces coefficient-table size while retaining simple address logic. MiniBit optimization and output rounding guarantee 1 ulp accuracy.

## families
### hierarchical  (role: proposes)
mechanism: Segmentation is applied recursively. Each level selects uniform segments or segments whose sizes increase/decrease by powers of two, and each outer segment can receive a different number of uniform inner segments. A balanced-error segmentation guides scheme selection through histogram variance. ROM0 stores each outer segment's inner address width and ROM1 offset, while ROM1 stores spline coefficients. Leading-zero/leading-one detection and barrel shifting derive the coefficient address. Reported implementations use two levels. # p.105-p.111

### piecewise_poly  (role: instantiates)
mechanism: Each segment stores Chebyshev polynomial coefficients. Horner's rule evaluates degree-1 or degree-2 splines using a segment-local input coordinate. A coefficient transformation reduces coefficient dynamic ranges after local-coordinate scaling. MiniBit assigns fixed-point widths to coefficients/operators analytically, with truncation on internal signals and round-to-nearest on the output. The generated architecture is combinatorial and uses FPGA slices rather than dedicated RAM or multiply-add blocks. # p.105, p.111-p.113

## space_gaps
* The hierarchical family lacks choices for hierarchy depth, per-level segment-size scheme, automatic hierarchy selection, and outer-address-width search. # p.105-p.108
* The piecewise_poly `segments` domain excludes reported counts 7, 19, 28, and 80 and incorrectly constrains segment counts to multiples of four for this method. # p.109
* The piecewise_poly `range_reducer` slot lacks a `none` value for direct evaluation of compound functions over a supplied interval. # p.103-p.104
* The coefficient transformation from global input coordinates to segment-local coordinates is a separate piecewise_poly design choice absent from the vocabulary. # p.111-p.112

## open_questions
* The paper permits arbitrary hierarchy depth but reports hardware results only for two levels, so the merge pass must not assign an optimal general depth. # p.106-p.107
* The area advantage over uniform segmentation depends on function/degree/precision, so reduced segment count must not be treated as an unconditional total-area reduction. # p.113-p.114
