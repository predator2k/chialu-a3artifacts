## summary
Sanity-Check detects errors in fully-connected/convolutional DNN layers through spatial and temporal linear checksums. A software implementation needs no hardware modification, while a systolic-array extension removes most performance overhead with small area/power costs.

## families
### abft_checksum  (role: extends)
mechanism: Spatial checksums add a sanity neuron/filter whose weights and bias are the additive inverses of the original sums, so each output vector sums to zero. Temporal checksums accumulate input vectors across a batch, process the additive inverse as an additional input, and compare accumulated outputs with expected bias-dependent constants. The hardware implementation adds one systolic-array column, a spatial sum-reduction adder tree, input/output accumulators, threshold comparators, and synchronization logic. # pp.706-714

errors_and_checks: Spatial checksums guarantee detection of one weight/filter error, one bias error, or one output/computation error, but cannot detect input errors. Temporal checksums guarantee detection of one input error, all bias errors, or one output/computation error, but cannot detect weight errors. Their combination guarantees detection of three or fewer output/computation errors. Experiments report perfect error-caused-misprediction coverage and no false alarms; residue arithmetic may introduce rare aliasing. # pp.709-715
conditions: Floating-point deployment requires per-layer profiling and thresholds because rounding perturbs the invariants. Fixed-point deployment avoids round-off when full-width multiplication/accumulation results and quantized checksum operands are used. Residue arithmetic avoids wider accumulators but permits rare aliasing. Temporal checking costs one extra prediction per batch, producing a 1/(N + 1) throughput reduction. # pp.710-714
