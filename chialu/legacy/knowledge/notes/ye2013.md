## summary
The paper proposes a gracefully-degrading accuracy-configurable adder whose maximum sub-adder length and carry-in prediction length are independently reconfigured at runtime (pp.49-51). A DCT platform uses frequency-dependent modes to improve throughput/image-quality tradeoffs over an earlier accuracy-configurable adder (pp.51-53).

## families
### accuracy_configurable  (role: proposes)
mechanism: The GDA partitions an N-bit addition into k-bit basic units connected by multiplexers. Each multiplexer selects a carry from the less-significant unit or a local prediction component. Control signals combine units into longer sub-adders and activate hierarchical prediction components that observe more low-order operand bits. Maximum sub-adder length mainly controls worst-case error, while prediction length mainly controls error rate; both affect average error (pp.49-52).

errors_and_checks: Accuracy is evaluated by worst-case error (WCE), error rate (ER), average error (AE), and application-level PSNR; GDA44 is exact. No error detector/recovery or formal error bound is reported (pp.51-53).
conditions: Basic units may use any adder design scheme (p.49). Longer sub-adders reduce accuracy loss at greater effort, while observing more prediction bits increases prediction accuracy with power/delay cost (pp.49-50). Static-adder results use gate-level simulation with 1,000,000 random inputs (p.51). DCT results use n=8, the JPEG quantization matrix, and frequency-dependent mode scheduling; the paper warns that the selected modes are not guaranteed optimal for another application (pp.51-53).
evidence: §3, Figs. 3-5, Eqs. 1-4, Tables 1-3, Figs. 9-11 (pp.49-53)

### segmented_carry_speculative  (role: extends)
mechanism: Each 4-bit unit predicts its carry-in from preceding operand bits by expanding the generate/propagate recurrence and assuming the unknown earlier carry is zero. The hierarchical implementation combines 4-bit predictors through control logic that tests whether all intervening propagate bits equal one. Multiple components can be activated and combined to select a 4-, 8-, 12-, or 16-bit prediction window (pp.49-50).

## space_gaps
* `accuracy_configurable.mode_count` needs values through 16 for the paper's 4×4 configuration space (p.51).
* `accuracy_configurable.reconfig_grain` lacks a value for varying the carry-in prediction window independently of sub-adder grouping (p.51).
* `segmented_carry_speculative.prediction_window` needs the value 16 (p.51).
* `segmented_carry_speculative` lacks a choice for hierarchical composition of fixed-width prediction components (p.50).

## open_questions
* The paper does not identify the standard-cell technology/node, supply voltage, synthesis library, or operating frequency used for Tables 1-2.
* The paper states that any adder scheme can implement a basic unit, so the `sub_adder` slot cannot be assigned.
* The paper does not specify whether disabled prediction components are clock-gated, operand-isolated, or power-gated.
