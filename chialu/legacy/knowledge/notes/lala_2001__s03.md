## summary
The chapter classifies separable/nonseparable block codes and symmetric/unsymmetric/unidirectional errors, then defines parity, unordered, residue, cyclic, Hamming, Hsiao, and Reed-Solomon codes. # p.32-57
The chapter settles redundancy/error-coverage relations and attributes several unidirectional and error-correcting constructions to their primary papers. # p.35-58

## families
### berger  (role: defines | taxonomizes | extends)
mechanism: A conventional Berger code appends the complemented binary count of information-bit 1s under B1 encoding, or equivalently the binary count of 0s under B0 encoding. Modified Berger coding appends the zero count modulo t+1 and may encode those check bits again with a two-rail code. # p.35-36
choices:
  check_field: full_log (conventional); modulo_reduced (modified)   # p.35-36
  granularity: endpoint   # p.35-36
new_choices:
  count_encoding: {B0, B1} — selects a zero count or complemented one count   # p.36
  length_class: {maximal, non_maximal} — maximal means k = 2^c - 1   # p.36
slots:
  comparator: UNKNOWN   # p.35-36
parameters: k information bits; c = ceil(log2(k + 1)) conventional check bits; c = ceil(log2(t + 1)) modified check bits   # p.35-36
results:
| metric | value | unit | technology / device | baseline | condition | page |
| check-bit count | ceil(log2(k + 1)) | bits | abstract | UNKNOWN | conventional Berger code | p.35 |
| modified check-bit count | ceil(log2(t + 1)) | bits | abstract | conventional Berger code | detects unidirectional errors of length t | p.36 |
errors_and_checks: The conventional code detects single and arbitrary unidirectional multibit errors; the modified code detects unidirectional errors of length t in the information bits. # p.35-36

### residue  (role: defines | instantiates | analyzes)
mechanism: A separable residue code appends C = N mod m. A low-cost residue code selects m = 2^r - 1, partitions the information word into r-bit groups, and adds the groups modulo 2^r - 1 with end-around-carry binary adders. # p.44-45
choices:
  modulus: 2^r - 1 [outside domain]   # p.44
  granularity: endpoint   # p.44
  comparison_point: UNKNOWN   # p.44
  generator_style: modular_ripple   # p.45
  ops_per_checker: UNKNOWN   # p.44
new_choices:
  none
slots:
  comparator: UNKNOWN   # p.44
parameters: m check base; r >= 2; r-bit groups and r check bits for low-cost codes   # p.44
results:
| metric | value | unit | technology / device | baseline | condition | page |
| general check-bit count | ceil(log2 m) | bits | abstract | UNKNOWN | residue base m | p.44 |
| low-cost check-bit count | r | bits | abstract | UNKNOWN | m = 2^r - 1 | p.44 |
errors_and_checks: Residue codes detect errors in arithmetic results; low-cost residue codes support online detection of single-bit errors in logic circuits. # p.44
conditions: Missing positions in a partial r-bit group are treated as 0. # p.45
evidence: Section 2.3, p.44-45
