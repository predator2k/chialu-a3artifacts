## summary
The document proposes SARA, a segmented accuracy-configurable adder that predicts each segment carry from an existing generate bit and requires only boundary MUXes beyond a ripple-carry adder (§III.B). SARA-DAR adds delay-adaptive self-configuration that enables approximation only when a long carry-propagation chain is detected (§IV).

## families
### accuracy_configurable  (role: proposes)
mechanism: SARA divides an N-bit ripple-carry adder into K segments and selects accurate or predicted carries at segment boundaries. The predicted carry reuses the boundary full adder's generate bit, so SARA contains no redundant computation or error detection/correction circuit. SARA-DAR examines W propagate bits above a boundary and selects the predicted carry only when all W bits propagate (§III.B, §IV).
choices:
  mode_count: 8 for SARA4; 4 for SARA8   # §III.C, §V.B
  reconfig_grain: carry_chain_switch   # §III.B
  error_detection: false   # §I, Table I
new_choices:
  configuration_policy: {external_static, delay_adaptive_self_configuration} — the boundary MUX is controlled by an application configuration or by detected carry-chain length   # §III.C, §IV
  detection_window_bits: W — the number of higher propagate bits inspected by SARA-DAR   # §IV
slots:
  none
parameters: N-bit adder; K = ceil(N/L) segments; L-bit sub-adders; 2^(K−1) physical settings but K effective critical-path configurations; evaluated as 32-bit SARA4/SARA8; Figure 5 uses W = 2; unpipelined implementation; default 1.25V   # §III.B–C, §IV, §V.A–B

errors_and_checks: No error detection/correction circuit is present (§I, Table I). For static prediction, ER_i^prdt = P(c_i−1 = 1)P(p_i = 1), assuming independence; for SARA-DAR, ER_i^dar = ER_i^prdt product from j=1 to W of P(p_i+j = 1) (§III.D, §IV). PSNR/worst-case error/error rate use 100K-run Monte Carlo simulation with uniformly distributed addends (§V.A).
conditions: Larger K shortens the approximate critical path but increases expected error and area (§III.D). SARA's effective critical paths span L, 2L, ..., K·L full-adder stages across its effective configurations (§III.C). SARA-DAR bounds the example approximate/accurate carry chains by L+1/L+2 bits, while a general W-bit detector gives an accurate-mode length of L+W (§IV). Iso-delay power comparisons scale voltage to a 0.82ns critical path (§V.D). The DCT experiment assigns higher accuracy to low-frequency components and more approximation to high-frequency components (§V.E).
evidence: Table I; equations (4)–(9); Figures 3–6 and 8–12; §§III–V.

### segmented_carry_speculative  (role: extends)
mechanism: K disjoint L-bit ripple-carry segments are joined by configurable MUXes. At boundary bit i, the approximate carry is c_i^prdt = g_i rather than a carry propagated through lower bits. The next segment's carry uses the selected boundary value, while its first sum uses the accurate local carry, which improves accuracy without extending the approximate critical path (§III.B).
choices:
  sub_adder_width: 4 for SARA4; 8 for SARA8   # §V.B
  prediction_window: 0 for static SARA; 2 in the illustrated SARA-DAR detector   # §III.B, §IV
  carry_in_scheme: generate_bit_prediction [outside domain]   # §III.B, equations (4)–(6)
  correction: none   # §I, Table I
new_choices:
  sum_carry_source: exact_local_carry — the first sum above a boundary uses c_i rather than selected ĉ_i   # §III.B, Fig. 3(c)
slots:
  sub_adder: ripple_carry   # §II, §III.B
parameters: N bits; K = ceil(N/L); evaluated at N = 32 and L = 4/8; approximate critical path roughly L full-adder stages before DAR detector overhead   # §III.B–C, §V.A–B
results:
| metric | value | unit | technology / device | baseline | condition | page |
| PDP | about a half | baseline PDP | Nangate 45nm Open Cell Library, 2018 | GDA or CRA | SARA4/SARA8 at 100 dB PSNR | §V.B, Fig. 6 |
| area reduction | 39% | % | Nangate 45nm Open Cell Library, 2018 | RAP-CLA | average routed area of the entire SARA design | §V.D, Fig. 11 |
errors_and_checks: An error occurs only when c_i−1 = 1, p_i = 1, c_i^prdt = 0, and c_i = 1 (§III.D). No correction circuit is provided (§I, Table I).
conditions: Reusing g_i avoids a dedicated prediction network (§III.B). Using c_i for the first higher-segment sum improves accuracy with almost no additional overhead (§III.B). SARA-DAR reduces errors for short actual carry chains but adds detector logic and may consume more power (§IV, §V.E).
evidence: Table I; Figures 3–5; equations (4)–(9); §§III–V.

## space_gaps
* segmented_carry_speculative.carry_in_scheme lacks `generate_bit_prediction`, where c_i^prdt = g_i (§III.B).
* accuracy_configurable lacks a configuration-policy choice distinguishing externally selected modes from delay-adaptive self-configuration (§III.C, §IV).
* segmented_carry_speculative lacks a choice for using the accurate local carry on the first sum while using the predicted carry for higher carry propagation (§III.B).

## open_questions
