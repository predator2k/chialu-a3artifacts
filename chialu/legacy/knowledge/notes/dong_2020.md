## summary
PLAC approximates nonlinear unary functions with error-flattened piecewise-linear segments, a bisection-based nonoverlapping segmenter, and a hardware-aware coefficient/output quantizer. The implementation evaluates log2(1+x), tanh(x), sigmoid(x), and softsign(x) with one multiplier/adder datapath and simplified coefficient indexing.

## families
### pwl  (role: extends)
mechanism: PLAC fits each nonuniform input segment with k×x+b and vertically shifts the segment to equalize its positive/negative maximum absolute errors. A bisection window finds the widest segment satisfying MAEsoft, while adjacent discrete segments use nonoverlapping endpoints. A software quantizer rounds k/b, truncates the product, and increases guard width until circuit error MAEc satisfies MAEhard. The circuit uses n−1 parallel constant-carry comparators, one n:1 MUX for concatenated k/b, one logic-reduced multiplier, and one adder. # pp.3–9
choices:
  segmentation: nonuniform [outside domain]   # pp.4–6
  slope_encoding: plain   # pp.3,7–8
new_choices:
  error_distribution: flattened — each segment is constructed to have the same MAEsoft bound   # pp.3–6
  endpoint_policy: nonoverlapping — adjacent segments do not reuse a discrete endpoint   # pp.4–6
  coefficient_quantization: rounded_fixed_point — k and b are rounded to qw fractional bits   # p.7
  product_quantization: truncated_fixed_point — kq×x is truncated to qw fractional bits   # pp.7–8
  hardware_error_control: QF_guided — MAEhard=MAEsoft×QF guides the minimum qw search   # pp.7–9
slots:
  segmenter: nonuniform [addressing=comparator_tree, boundary_search=bisection [outside domain]]   # pp.4–6,8
parameters: log2(1+x): input range [0,1], iw=23 for the segmentation benchmark; log2(1+x) accuracy experiment: 7 segments, MAEsoft=8.84e–4, QF=1.03 gives qw=16 and MAEc=9.05e–4, while QF=1.2 gives MAEc=1.05e−3; softplus(x): 16 segments; softsign(x): 16 segments; sigmoid ASIC experiment: 2 segments at MAEsoft=8.17e−4; tanh ASIC comparison with [23]: iw=8, MAEsoft=2.201e−3, 5 segments for [23], QF=3.15, qw=8   # pp.6,8–12

errors_and_checks: The contract is MAEc≤MAEhard. MAEc is maximum absolute error after fixed-point coefficient/product quantization; the quantizer searches the minimum qw satisfying the bound. For log2(1+x), MAEsoft=8.84e–4 and QF=1.03 produce MAEhard=9.11e–4 and MAEc=9.05e–4. # pp.7–9
conditions: PWL requires one MAC and coefficient/endpoint storage, so memory scales with the number of segments. A smaller QF tightens MAEhard and increases qw/hardware resources, while a larger QF reduces qw and degrades the flattened-error property. The claimed theoretical-best segmentation result applies to logarithmic function; universality is demonstrated on other unary functions without the same proof. # pp.1–2,6,9
evidence: §§III–V; Figs. 3–8; Tables I–X, pp.4–12

### nonuniform  (role: extends)
mechanism: The segmenter discretizes the input domain and uses a bisection window to maximize each segment width under MAEsoft. The left/right pointers move according to whether the candidate endpoint satisfies the error bound. The stopping tests ep==rp and ep==rp−1 identify the maximum valid endpoint, and the next segment starts at a nonoverlapping discrete input point. # pp.4–6
choices:
  addressing: comparator_tree   # pp.3,8
  boundary_search: bisection [outside domain]   # pp.4–6
new_choices:
  endpoint_overlap: disallowed — consecutive segments use distinct discrete endpoints   # pp.4–6
slots:
  none
parameters: discrete input x(1:NUM); pointers sp/ep/lp/rp; target MAEsoft; log2(1+x) benchmark range [0,1), iw=23   # pp.3–6

## space_gaps
* The `pwl` family lacks choices for error-flattened segmentation, nonoverlapping discrete endpoints, coefficient/product quantization, and QF-guided circuit-error control. # pp.3–9
* The `nonuniform.boundary_search` domain lacks `bisection`, which PLAC uses to maximize segment width. # pp.4–6
* The `pwl` family lacks a segmenter slot even though PLAC makes the segmentation algorithm a primary architectural design choice. # pp.3–6
