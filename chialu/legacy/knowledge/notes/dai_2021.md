## summary
APIR-DSP replaces the six exact 9×9 multipliers in PIR-DSP with approximate multipliers built from modified 3×3 truth-table blocks. The block supports signed/unsigned low-precision MAC operations and reduces area/power/delay with small reported FIR/DNN accuracy losses. A Yosys/VPR platform evaluates APIR-DSP against DSP48E2 on GEMM and DoReFaNet workloads.

## families
### multiprecision_block_proposal  (role: extends)
mechanism: PIR-DSP partitions a 27×18 multiplier into six signed/unsigned 9×9 multipliers and arranges shifted partial results into two columns for parallel MAC operations. APIR-DSP replaces all six exact multipliers with approximate 9×9 multipliers while retaining the input register file and semi-2D cascade interconnection. Yosys pre-packs six multiplications and eligible input registers into each block, and VPR models placement/routing. # p.3–5

### approximate_compressor  (role: proposes)
mechanism: An unsigned 9×9 multiplier is partitioned into nine 3×3 multipliers whose shifted 6-bit partial results are summed. The approximate 3×3 block changes six of 64 truth-table outputs to simplify four output logic functions. Signed operation extracts operand signs, converts operands to 2’s complement form, performs unsigned multiplication, XORs the signs, and conditionally complements the result. # p.3–4

## space_gaps
* `multiprecision_block_proposal.fracture_to` lacks the six-way 27×18-to-six-9×9 partition used by PIR-DSP/APIR-DSP. # p.3
* `approximate_compressor.segment_width_bits` excludes the proposed 3-bit tile width. # p.3
* `approximate_compressor` lacks a choice for truth-table-output modification as the approximation mechanism. # p.3

## open_questions

* The paper does not report separate error metrics for signed 9×9 multiplication; the detailed metrics cover the unsigned core or its unsigned 8×8 subset. # p.3–6
