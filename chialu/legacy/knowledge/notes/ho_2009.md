## summary
The document proposes an FPGA architecture that combines fine-grained logic with runtime-reconfigurable coarse-grained blocks containing floating-point adders/multipliers and word-oriented logic. The document also proposes the virtual embedded block methodology for estimating the area/delay of new embedded blocks with commercial FPGA tools. The modeled architecture reduces area by 25 times on average and reduces delay by 3.6 times for single precision and 4.3 times for double precision against Xilinx Virtex II implementations.

## new_families
### floating_point_coarse_grained_fpga  (domain: dsp: FPGA DSP blocks, closest: hard_fp_dsp, why_not: hard_fp_dsp places hardened floating-point arithmetic inside a DSP block, while this document proposes parameterized runtime-reconfigurable coarse-grained blocks with multiple FP operators/wordblocks and bus-oriented routing.)
mechanism: Dedicated columns of coarse-grained units coexist with island-style fine-grained logic. Each coarse-grained unit contains registered floating-point multiplier and adder/subtractor subblocks plus wordblocks made from identically configured bitblocks. Unidirectional bus-oriented multiplexers connect subblocks, and feedback registers support accumulation and right-to-left dependencies. Multiplier subblocks precede adder subblocks to support multiply-and-add without a feedback register. Design-time parameters control the number/type/placement of subblocks, buses, and feedback registers, while configuration bits reconfigure the resulting block at runtime.

## space_gaps
* The dsp vocabulary lacks a family for a parameterized coarse-grained FPGA block that combines multiple registered FP add/subtract/multiply operators, wordblocks, runtime configuration, bus-oriented routing, and feedback registers (p.1711).
* The proposed family needs design choices for subblock count/placement, input/output bus counts, and feedback-register count because these parameters define the explored architecture (pp.1711,1715).
* The hard_fp_dsp `fp_format` domain lacks fp64, although the document evaluates a double-precision coarse-grained FPGA architecture (p.1717).
* The vocabulary lacks a slot for the internal floating-point adder/multiplier implementations, whose arithmetic microarchitectures are not disclosed by the document (pp.1714-1715).

## open_questions
* The document does not identify the internal arithmetic families used by the synthesized IEEE 754 floating-point adder and multiplier.
* The document states that the floating-point library supports four rounding modes and denormalized numbers but does not enumerate the four modes (p.1714).
* The document does not provide a fabrication year for any modeled result.
* The reported area/speed gains are upper-bound estimates because the benchmark set strongly represents kernels that map directly to the coarse-grained units, while dependencies/control/interfacing can degrade performance (p.1713).
* The document states that gains decrease for larger circuits or circuits with more random logic relative to floating-point operations (p.1717).
