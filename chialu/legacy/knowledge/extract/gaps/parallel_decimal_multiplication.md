# parallel_decimal_multiplication: proposed changes to the space

* `reduction_tree` slot admitting `decimal_multioperand_addition`, `redundant_decimal_addition`, a signed-digit decimal reduction and a column-wise binary-then-BCD reduction — the decimal compressor trees, the DSSD adder, the [-8, 8] signed-digit adders and the shared binary/decimal column reduction all perform the partial-product reduction [castellanos_2008, gorgin_2009, han_2013, han_2016, schmookler_1972, wahba_2017]
* `final_adder` slot admitting decimal adders (`bcd_direct_addition`, the conditional-speculative decimal adder, an SD-to-BCD hybrid prefix converter) and `none` for redundant products that feed an FMA adder directly, since every implementation terminates in a decimal CPA rather than a binary one [erle_2009, hickmann_2007, lang_2006, samy_2010, vazquez_2010, vazquez_2014, han_2013, han_2016, gorgin_2009]
* `internal_digit_code` values for the redundant encodings: 4-bit two's-complement signed digits in [-8, 8] or [-8, 7] with a shared increment bit, the DSSD set [-7, 7], and a mixed 4221/5211 tree as one value, plus separate codes for partial products and carry/sum outputs (4221 rows, 8421 outputs) [han2013, han_2013, han_2016, gorgin_2009, vazquez_2010, hickmann_2007]
* `multiplier_recoding` values for a generic undisclosed signed-digit set, the `sd_radix5` recoding Bi = 5 BiU + BiL, and the explicit yH in {0, 5, 10} plus yL in [-2, 2] form [samy_2010, wahba_2017, lang_2006]
* `pp_generation` values `direct_8_variable_rom` for simultaneous digit-product truth tables and an unsigned double-BCD basis {X, 2X, 5X, 8X, 9X}, with a `precomputed_multiple_set` choice naming the set ({1X..5X}, {±X, ±2X}, {±X, ±3X, ±4X}, {0X..5X in XS-3}) [schmookler_1972, jaberipur_2009, gorgin_2009, vazquez_2014]
* choices `reduction_optimization: {area_optimized, delay_optimized}` for the p:2 CSA-tree organization and `converter_prefix_partition: arrival_balanced_hybrid` for the final converter [vazquez_2010, han_2013]
* choices `partial_product_sign_control: per_product_increment_bit`, `partial_product_digit_set: [-6, 6]` and `final_digit_set_conversion: {performed, omitted}` for the redundant-encoding designs [han2013, han_2013, han_2016]
