# online_arithmetic_unit: proposed changes to the space

* choice `operation: {addition_subtraction, multiplication, division, square_root, composite_function, remainder}` with an `operation_set` for programmable units and token-based demand flow control — the surveyed recurrences differ by operation, and the large-number unit selects among five [ercegovac_1984, oklobdzija_1982, guyot_1989]
* `radix` admitting a general r, including 10, 128 and 256 — the recurrences and digit-set bounds are parameterized by r, and the demonstrated units use radices outside {2, 4, 8, 16} [ercegovac_1984, oklobdzija_1982, vazquez_2013]
* `digit_set` values for intermediate redundancy, an over-redundant set (0 through 6) and an explicit BSD posibit/negabit encoding — r/2 <= p <= r-1 admits intermediate sets, the sum-of-squares output is over-redundant, and the radix-2 units encode digits as bit pairs [ercegovac_1984, ercegovac_lang_1988, taghavizade_2024]
* `residual_form` value `borrow_save` — the exponential/logarithm/powering architecture keeps every iterative variable in borrow-save form [vazquez_2013]
* choices for digit selection: `digit_selection: {selection_constants, residual_rounding, signed_nearest_integer}`, `residual_estimate_digits` or `selection_estimate_fraction_bits`, and `selection_constant_generation: {table_lookup, successive_approximation, hybrid}` — the selection hardware is set by estimate width and constant generation [ercegovac_2004#s01, ercegovac_lang_1988, oklobdzija_1982, trivedi_1977]
* `online_delay` per operator inside a composed datapath, plus `digits_per_cycle` — the GELU pipeline has adder delay 2 and multiplier delay 3, and the online CORDIC angle recurrence groups three signed digits per clock [taghavizade_2024, ercegovac_lang_1990]
* choice `output_combination: {single_module, average_both_modules}` — averaging two branching CORDIC modules cuts the online delay from 6 to 5 and tightens the error bound [duprat_1993]
* choices `implementation_organization: {linear_nonpipelined, one_dimensional_pipelined, two_dimensional_pipelined}`, `variable_precision: Bool` and `digit_order: {msdf, lsdf}` — the modular array organization, precision matching and digit order decide which operations meet a bounded online delay [ercegovac_1984, irwin_owens_1987]
* a result-conversion/rounding slot for `on_the_fly` conversion with `result_rounding: {exact_sign, no_sign, estimated_sign}` [ercegovac_1992, ercegovac_lang_1988]
* choices for the E-method: problem-to-linear-system correspondence, selection overlap/precision, execution-time scaling, and component slots for the multioperand adder and signed-digit selection network of each elementary unit [ercegovac_1977]
* choices `residual_control: fitter_limiter_sign_detector`, `operator_size_scaling: {bounded, proportional, superlinear}` and `realization_model: finite_automaton_transducer` — the DNN engine bounds its residual with a fitter and limiter, and the automaton model classifies operators by size scaling [moghaddasi_2024, muller_1994]
