# ai_tensor_block: proposed changes to the space

* accumulate_format values int16 and int48 — int16 is the native int8 accumulation format of the Tensor Slice and int48 serves its int16 mode. [arora_2021, arora_2022]
* element_format values int16, int3, fp24, and shared-exponent block FP12/FP16, with bf16 named bfloat16 — commercial and academic blocks support these natively and the space does not separate block floating point from IEEE formats. [arora_2022, boutros_2021, langhammer_2021, rasoulinezhad_2021, taka_2025]
* dot_width admits 10, and separates total MAC count from runtime-selected dot lengths/counts — the Stratix 10 NX dot product is ten elements, which the step-of-four domain excludes, and MLBlock projections form several dot lengths from one MAC count. [boutros_2020, langhammer_2021, roorda_2022, rasoulinezhad_2021]
* choices runtime_mode_selection, tensor_operations/operation_set, scalar_fracturing/individual_pe_exposure, precision_fracturing, bias_preload, tiled_accumulation, and local_input_crossbar_population — the Tensor Slice selects operation and precision at runtime, exposes PEs individually, preloads accumulators, and sits behind a 50% populated crossbar. [arora_2021, arora_2022]
* choice for precision-dependent matrix shape and MAC count (4x4/16 MACs fp16 versus 8x8/64 MACs int8) — the native shape follows the element format. [arora_2021]
* choices dot_units_per_block, accumulators_per_block, and operand_delivery (broadcast_plus_ping_pong_cascade) — the NX block has three dot units, three optional accumulators, and one broadcast operand set beside cascaded reuse banks. [boutros_2020]
* choices operating_mode {tensor, vector, scalar}, weight_loading {parallel, side, cascade}, shared_exponent width, and maximum cascade length — these set operand reuse, loading bandwidth/routing, block floating-point operands, and chains of up to 36 blocks. [langhammer_2021, roorda_2022]
* choice dataflow {weight_stationary, output_stationary} — MLBlock and the modeled NX block are weight-stationary while the sparse slice is output-stationary. [rasoulinezhad_2021, roorda_2022, taka_2025]
* choices projection_routing (runtime_selected_projection_set), input_windowing (one_dimensional_configurable), configuration_selection {greedy, n_config}, mac_units_per_block {6, 8, 9, 12}, and precision_extension (serial_parallel_multiplier) — MLBlock's projection vector, windowing registers, and serial-parallel 16-bit reuse are its central tunables. [rasoulinezhad_2021]
* choice access_pattern_factors (AP1-AP5) — the factor vector determines which workload dimensions can be unrolled inside the block. [roorda_2022]
* choice physical_layout {single_column, grouped_columns, clusters, irregular_columns} — grouped blocks concentrate routing near the blocks and change congestion and frequency. [roorda_2022, arora_2022]
* choices structured_sparsity_modes {dense, 2:4, 1:3, 1:4}, sparse_storage (index_based_2bit), and dedicated_interconnect_axis (vertical_B_operand) — the sparse slice selects weight patterns at runtime, carries a 2-bit index per nonzero, and forwards B operands over dedicated vertical wires. [taka_2025]
* choice operand_reuse_network {double_buffered_registers, bram_plus_circular_register_file} — local reuse expands internal operand bandwidth beyond the routing interface. [boutros_2021]
