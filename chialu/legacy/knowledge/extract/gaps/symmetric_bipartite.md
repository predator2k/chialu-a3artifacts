# symmetric_bipartite: proposed changes to the space

* `function` value `square_root` (or `all_three`) — the modified SBTM also supplies direct square-root initial approximations [schulte_1999]
* choice `omitted_input_partition: {none, midpoint_replacement}` — the low partition x3 is dropped from the table address and replaced by its midpoint, which costs one extra guard bit [schulte_1999]
