# compound_flagged_prefix: proposed changes to the space

* `outputs` values for plus-2 and complemented result sets (`sum_sum1_sum2`, `sum_sum2`, R/R+1 with a selection-derived R+2, the eight-way A+B..B-A set, and sum with sum+1 and the inverted sum as H0, H1 and HC) — rounding after significand overflow, three-candidate normalization, decimal rounding and the end-around-carry select all need a candidate that the current two values cannot express [beaumont_smith1999, beaumont_smith1999, langhammer_2015, langhammer_2015b, lichtenau_2016, mueller_2005, quach_2004, vazquez_2009]
* choice `output_logic_scope: {full, late_increment_only, absolute_difference_only}` — dedicated increment-only and absolute-difference cells simplify the controls and cut the transistor count below the full inc/cmp cell [burgess2002]
* `implementation` value `shared_generate_propagate_strings` — the incremented sum is formed as OR(Gen_C, Prop_C) on the same prefix strings as the ordinary sum, which is neither a flag row nor a second carry tree [seidel_2001]
* choice `pipeline_partition: {none, prefix_state_then_xor}` — the prefix state crosses a stage boundary and only one XOR line for the incremented sum remains in the second stage [seidel_2001, seidel_2004]
* choice `prefix_preprocessing: {none, half_adder_row}` — a half-adder row before the tree converts kill/generate patterns into propagate strings for flag detection [beaumont_smith1999, beaumont_smith1999, langhammer_2015b]
* choice `rounding_positions: {one, three}` — three-operand addition can overflow by two, one or zero bits and needs three rounding positions on the compound result [sohn_2014]
* choice `decimal_trailing_nine_detection: Bool` — decimal instances compute flags for trailing nines rather than trailing ones, with separate flagADD/flagSUB networks [wang_2007b, vazquez_2009]
* an absolute-subtraction output that selects A-B or B-A from the subtraction sign — the textbook lists it as a related construction of the same tree [muller_2018]
* `topology` values outside the prefix graphs, `carry_lookahead` and `ling` — one compound adder is a carry-look-ahead structure rebalanced for the wire delays of a folded datapath, and another propagates its global carry by a modified Ling scheme [mueller_2005, quach_1991]
* `implementation` value `conditional_sum` — the compound adder reuses the conditional-sum local sum logic that a high-speed adder already carries, so it costs little more than a plain adder [quach_1991]
* choice `carry_out_acceleration: {none, precomputed_select_sets, carry_only_replica}` — deriving the result selects from the carry-out is the critical path, and it is broken either by precomputing both select sets or by a carry-only network beside the main tree [mueller_2005, oh_2006]
* choice `block_polarity: {uniform, alternating_true_complement}` — the lookahead carry structure of the end-around-carry compound adder is built from alternating true and complement blocks [oh_2006]
