# carry_select: proposed changes to the space

* `duplication` values `shared_primary_functions`, `or_gate_derived_second_carry`, `dual_carry_chains_single_sum_generator` and `time_multiplexed_shared` — the origin shares the A OR B and AB primaries between the two paths, the reduced-area scheme derives the carry-in-1 carries as c1 = c0 OR P, the PA7100 rounding adder keeps two carry chains but one sum generator, and the CSAS evaluates Cin=1 then Cin=0 in one block across half-cycles with transparent latches [bedrij1962, tyagi1993, asprey_1993, amelifard2005]
* `block_sizing` values `delay_balanced_analytical`, `delay_balanced_sections`, `arrival_profile_optimized` and delay-matched prefix-block growth (adjacent sizes j and 2j) — the sizings in use derive from full-adder/mux/latch delays, section delay balancing, the final-adder arrival profile (with boundaries S1/S2 from the profile intersection) and prefix-block delay matching, none of which the current values name [amelifard2005, asprey_1993, stelling1996, oklobdzija1996, tyagi1993]
* `select_source` values for the CCC/CR and CAC fast-carry-chain networks, a hierarchical multiple-radix group-carry network, a nearest-neighbour cascade combined with distributed long-word lookahead, and a multilevel section carry — the FPGA AAM, the origin 100-bit adder, the Alpha 21064 and the PA7100 each drive their selects from a network outside the rippled/tree pair [pasca_2011#s06, bedrij1962, dobberpuhl_1992, asprey_1993]
* choice `carry_hierarchy: {single_level, multilevel_multiple_radix}` — sections form groups whose X/Z carry functions combine at successive levels [bedrij1962]
* explicit `block_width` choice — the 8-b duplicated carry-chain groups of the Alpha 21064 and the 8-bit POWER6 blocks have no parameter to land on [dobberpuhl_1992, eisen_2007]
* choice `select_sum_fusion: {separate, fused_one_gate}` — carry selection and sum generation occur in a single gate on the critical path [naffziger1996]
* choices for arrival-profile regioning (`arrival_profile_regioning: three_regions`, `region_boundary_method: iterative_integer_search`, region-specific block styles) and a `block_count` limit — multiplier final adders assign different structures to the positive-slope, maximum-delay and negative-slope regions and permit one carry-select block [oklobdzija1995, oklobdzija1996, stelling1996]
* `block_adder` slot admitting `parallel_prefix` and heterogeneous nested subblocks — the select-prefix construction uses a prefix adder inside each selection block and the hybrid timing formulation nests subblocks [tyagi1993, stelling1996]
* a checker slot fillable by `two_rail_tree`, with choices `checking_granularity: cascaded_2_bit_cells`, `checker_input_configuration: direct_pair_plus_exnor_pair` and `self_checking_mux_style: four_transmission_gates_plus_inverter` — the self-checking carry-select adder is built from these [vasudevan_2007]
* `sparse_prefix_hybrid.sum_block` admitting `carry_select` — the measured hybrid uses modified carry-select sum blocks [dimitrakopoulos2005]
* choice `inverse_propagate_support: Bool` — the FPGA chain keeps both configurable carry polarities [hauck2000]
