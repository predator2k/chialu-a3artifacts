# exponent_path: proposed changes to the space

* concurrent serial exponent unit beside the parallel mantissa unit (Stretch) as an execution-style value [bloch_1959]
* separate internal representations per format with their own biases as a bias_handling value [gerwig_2004]
* exponent adder speed/size choice — a small slow exponent adder overlapped with the significand product [muller_2018]
* precision-dependent duplication of the exponent datapath in SIMD units [huang_2007]
