# approximate_logic_synthesis: proposed changes to the space

* `method` values `gate_pruning`, `stochastic_gate_transform`, `boolean_matrix_factorization`, `bdd_rewrite`, `aig_rewrite`, `bit_width_reduction`, `operator_substitution`, `expression_rewrite`, `loop_transform` — the survey's structural, rewriting and high-level transformations are not covered by the four declared methods [scarabottolo2020]
* `method` value `wire_by_switch_exhaustive_search` — enumerating every wire as unchanged/tied-0/tied-1 with exhaustive simulation is a distinct synthesis method [tasoulas2020]
* `method` value for DFG-level joint selection of algorithmic/logic/VOS approximations with learned error propagation [zervakis2019]
* choice `abstraction_level: {gate_netlist, boolean_representation, behavioral_rtl_c}` — the representation the approximation operates on distinguishes the surveyed methods and is orthogonal to `method` [scarabottolo2020, nepal2014]
* choice `search_strategy: {greedy, exhaustive_bounded, stochastic, evolutionary, pareto_evolutionary, integer_linear_programming, verifiability_driven, iterative_stochastic_greedy}` — how candidate transformations are selected, including the verifier-aware search that accepts only candidates proved within a resource limit [ceska2017, scarabottolo2020, nepal2014, vasicek2015]
* choice `candidate_representation: {gate_level_cgp, standard_cell_cartesian_grid_dag, functional_level, abstract_syntax_tree}` — CGP node granularity (Boolean gate, standard cell, word-wide component) and the AST of behavioral synthesis are distinct representations [ceska2017, mrazek2017, vasicek2015, nepal2014]
* choice `fitness_objective: {relative_gate_area, MRE_power_delay, accuracy_power_area_weighted, power_at_fixed_delay, sum_absolute_error}` with an `optimization_orientation: {area_oriented, error_oriented}` split — which quantity the search minimises and whether resources or an error bound constrain it [ceska2017, mrazek2017, nepal2014, tasoulas2020, vasicek2015]
* choice `verification_resource_limit` (conflicts per AIG node) — the per-query bound on verifier work is a tunable of SAT-driven synthesis [ceska2017]
* `error_constraint` values for a generic user-defined quality function, an absolute error bound and a relative error bound — SALSA's Q-function accepts any Boolean quality metric and the survey cites relative error as the example [mittal2016, venkataramani2012]
* choice `error_evaluation: {exhaustive_all_inputs, sampled_simulation, formal}` — exhaustive evaluation at 8 bits versus 10^9 sampled vectors at 16 bits changes what the reported error means [mrazek2017, ceska2017]
* choice `exact_function_constraint` (Bool, e.g. exact multiplication by zero) — an application-specific exactness requirement added to the error bound [mrazek2016]
* choice `population_seeding: {random, heuristic_interleaved, heuristic_precomputed, conventional_architectures}` — seeding from evolved or conventional circuits changes convergence by an order of magnitude [vasicek2015, mrazek2017]
* choice `search_parallelism: island_populations_with_migration` — multi-island NSGA-II with migration is a distinct execution of the search [mrazek2017]
* choices `scalability_heuristic: {equate_unapproximated_outputs, quality_function_decomposition, input_output_dependency_restriction, subset_adc_computation}` and `synthesis_backend: off_the_shelf_logic_synthesis` — the don't-care method's scaling options and its reliance on an external synthesis tool [venkataramani2012]
* choice `optimization_granularity: output_bit` — output-by-output simplification is the iteration unit of don't-care synthesis [mittal2016]
* choice `candidate_objective: deletion_downsizing_error_score` — the substitution method ranks target/substitute pairs by removable logic, timing slack and difference probability [venkataramani2013]
* choice `transformation_operator: {data_type_simplification, operation_transformation, arithmetic_expression_transformation, variable_to_constant_substitution, loop_transformation}` — the behavioral operator set that `method: behavioral_transform` alone does not distinguish [nepal2014]
