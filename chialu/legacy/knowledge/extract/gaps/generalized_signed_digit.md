# generalized_signed_digit: proposed changes to the space

* `radix` admitting any integer r >= 2, the 2^k formulation beyond 16, radix 10, and one implementation shared across radices 8 and 10 — the framework papers, the multibit recoder, the decimal multipliers and the combined binary/decimal FMA all fall outside {2, 4, 8, 16} [avizienis_1961, parhami_1990, samgupta1990, erle_2005, han_2013, wahba_2017]
* choices `digit_bounds` (alpha, beta), `redundancy_index` (rho = alpha + beta + 1 - r), `allowed_digit_set` and a symbolic bound parameter — asymmetric sets and rho decide propagation, negation and detection behaviour beyond the minimal/intermediate/maximal triple [avizienis_1961, parhami_1990, parhami_1993, muller_1994]
* `digit_encoding` values for the positive/negative flag pair (posibit/negabit, x+/x-, (n,p), two-signal 00/01/10), the S = S* - S** difference code and the five-bit Svoboda decimal code with one's-complement inverse — most radix-2 designs use a bit-pair code the current values do not name [chen2018, ercegovac_2004#s01, guyot_1989, harata_1987, moghaddasi_2024, parhami_1990, srinivas_parhi_1992, takagi_1985, taghavizade_2024, erle_2005]
* `final_conversion` values `sign_select_parallel` and `sd_bcd_hybrid_prefix_conversion`, and a `rounding_during_conversion: {exact_sign, no_sign, estimated_sign}` refinement of on-the-fly — the converters on file are more than the cpa/on-the-fly pair [srinivas_parhi_1992, han_2013, ercegovac_1992]
* choices `transfer_span: {one_position, two_positions}`, `space_zero: Bool` and a canonical minimal/nonadjacent recoding rule — the origin paper and the Tocher recoding define these as separate decisions [avizienis_1961, tocher_1958]
* choice `representation_subclass: {OSD, SC, SB, BSD_or_BSB, SCB, BSCB, SDC, HDD}` and `subtraction_scheme: {propagation_free, limited_propagation}` [parhami_1990, parhami_1993]
* `generalized_signed_digit` admitted in `sequential_shift_add.step_adder` and `iterative_decimal_multiplication.accumulator` — the multiplication recurrences use a signed-digit adder or accumulator [avizienis_1961, erle_2005]
* choices `digit_set_by_stage`, `increment_bit_scope`, `representation_scope`, `intermediate_encoding: one_bit_sum_and_carry` and a `selection_overlap` parameter — the decimal multiplier, the RDNS accelerator, the modulo signed-digit adder and the recurrence selection each expose one [han_2013, moghaddasi_2024, wei_2014, ercegovac_1977]
