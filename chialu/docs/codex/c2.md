# C2: floating-point sharing gaps

## Implementation

1. **Rounders across formats.** Explicit partitions now support `dedicated_per_op` and `shared_per_lane`, as well as `shared_across_formats`. The selected inner families/pins are preserved. A bank at the union FP geometry muxes mutually exclusive modes through shared arithmetic cells. Simultaneous lane positions get independent instances; a lane outside a group gets its own selected module. Multiple independent groups of the same stage are supported. Plans no longer silently replace an explicitly requested rounder/unpacker family with `shared_across_formats`.
2. **Unpackers across formats.** The same grouping works for `per_unit_unpack` and `shared_per_lane`. Consumers use the shared decoded buses, including when their original family was `per_unit_unpack`. With `denormal_handling=in_unpack`, the selected LZC/shifter cells share. With `in_datapath`, mode-muxed exponent codes and biases feed one exponent subtraction; special-value decoding, DAZ, hidden bits, and stored significands keep their exact semantics.
3. **Same-mode FP8 adders.** Packed-SIMD FP addition was not implemented. Such lanes compute simultaneously, so the generator still refuses time-sharing. The error explicitly asks for a separate group per lane. This diagnostic also applies to the analogous same-mode FP multiplier/comparator groups found in the recorded candidate.

The implementation preserves selection/fidelity validation. Groups with different families or pins still refuse and explicitly request identical selections or separate groups. Groups with no common lane position also receive a repair instruction.
