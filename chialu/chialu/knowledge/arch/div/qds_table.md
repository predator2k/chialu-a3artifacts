# qds_table

Quotient-digit selection as a lookup that implements the P-D plot directly: decoders locate a truncated divisor (Nd fraction bits) and a truncated shifted residual (Np bits) in intervals, and the intersection names the next digit. Because the digit set is redundant, adjacent digit regions overlap, so the comparison constants can sit anywhere representable inside the overlap and a carry-save residual can index the table before assimilation. The practical radix-4 budget is about Np=6 and Nd=4 (the Pentium used seven residual and four divisor bits), and the examined width grows roughly as 3*log2(r).

The two truncation widths trade against each other: more residual bits and fewer divisor bits reduce product terms, delay and area at the price of a longer external assimilator, and table size is exponential in the index width, so the divisor width is minimized first and any valid (u,t) pair stays valid when either grows. The table sees a narrow top slice assimilated by a short adder (a 9-bit adder in the R3010, an 8-bit estimate ALU in the verified radix-4 core), whose width is assimilator_bits; a redundant two-word input widens the uncertainty interval and is the comparator family's residual_input, and a full assimilation is affordable only where the residual is already nonredundant (the recurrence's residual_form). Placing constants near the upper boundary of the overlap also cuts Np. Selection delay grows about linearly and area quadratically with radix, direct radix-16 and radix-32 tables are impractical, and radix 16 is built as two overlapped radix-4 selections with the second replicated per candidate digit; at radix 2 no divisor bits are inspected. folding halves the table through its sign symmetry, and digit_encoding sets how the digit leaves the table, a one-hot form driving the multiple selector directly at a PLA area cost. Divisor prescaling toward 1 removes the table altogether by turning selection into rounding.

The table is a generated artifact with a verification contract. Overlap tolerates either of two valid digits but does not recover from an invalid one: five entries of a 2048-entry radix-4 PLA that returned 0 instead of +2 pushed the residual out of range and left quotients with only 14 correct bits, reached through a foothold entry that random testing systematically undersamples. The generator regenerates the entries from the feasibility constraints and walks every P-D cell including the fenceposts that look unreachable, checking the containment bound (|p| <= 8/3 d at radix 4) for the table as built.

The seed instantiates the library's generated divider for this family
(`chialu/targets/rtl/families/div.py`: generated by `chialu.targets.rtl.families.div.qds_table` for the `divisor_truncation_bits` and `residual_truncation_bits` declared, every cell checked for containment of the next residual on both sides (the margin for the bits shifting in included) and widened until feasible, emitted as a case ROM in a module of its own over the divisor row and the estimate; the estimate assimilated over `assimilator_bits` through the residual adder, the digit in its `digit_encoding` (unencoded, one line per value, Gray or thermometer) and, under `folding`, the table over the estimate's magnitude alone with the sign applied after). `python3 -m chialu.targets.rtl.families.div --width 32 --family <family> --pins k=v,...` emits it for a rewrite (`--sqrt` for the square root).

## design choices

### digit_encoding

| member | what it selects |
| --- | --- |
| `unencoded` | the table entry is the signed digit itself. |
| `line` | one line per digit value, the most negative first. |
| `gray` | a Gray code of the offset digit, which changes one bit between neighbouring table cells. |
| `choose_highest` | a thermometer word whose line k is set when the digit is at least -a + 1 + k. |

### folding

| member | what it selects |
| --- | --- |
| `none` | the table holds a row per signed estimate. |
| `signed_magnitude` | the table holds the rows of the magnitude alone: a non-negative estimate reads its incremented value, a negative one reads its complement, and the digit read is negated, which the symmetry of the containment condition permits. |
